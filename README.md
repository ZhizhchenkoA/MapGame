# Игра с созвездиями

Сайт для игры двух участников на карте из 43 созвездий. Счёт, карточки и действия жюри хранятся в Google Таблице; сайт публикуется на GitHub Pages. [Правила для игроков](site/rules.html).

## Автор исходного проекта

**Все права на исходное изображение карты созвездий и идею игры принадлежат автору [iuriigrishin/svg-dashboard](https://github.com/iuriigrishin/svg-dashboard).** В этом репозитории карта использована для сайта игры.

## Запуск

1. В **Settings → Pages → Build and deployment** включите **GitHub Actions**. Workflow из `.github/workflows/pages.yml` публикует папку `site` после отправки изменений в `main`.
2. Создайте Google Таблицу. В **Extensions → Apps Script** вставьте [Code.gs](site/apps-script/Code.gs). В **Project Settings → Script properties** задайте `JURY_PIN`.
3. Запустите `setup()` и выдайте разрешения. Появятся листы `Games`, `Events`, `Tasks` и первая игра.
4. Опубликуйте скрипт через **Deploy → New deployment → Web app**: **Execute as Me**, **Who has access: Anyone**. Скопируйте адрес, заканчивающийся на `/exec`.
5. На сайте в **Настройках** введите адрес скрипта и PIN жюри. Кнопка **«Ссылка для игроков»** создаёт ссылку с адресом скрипта и выбранной игрой, без PIN.

При изменении `Code.gs` выпустите новую версию через **Manage deployments → Edit → New version**. После обновления страницы PIN жюри нужно ввести снова. Если сайт читает игру, но кнопка «Начать игру» не работает, проверьте `JURY_PIN` и версию развёрнутого скрипта.

## Задачи и управление

Лист `Tasks`: A — номер созвездия, B — название, C — условие с формулами LaTeX, D — ответ для жюри. Сайт показывает только условия взятых карточек; ответы не передаёт. Локальные файлы с задачами и ответами хранятся в `tasks/private/` и не публикуются.

Игру можно начать кнопкой на сайте после ввода PIN или флажком `B3` на её листе. Там же жюри отмечает взятие карточки, попытки, сброс и подсказку. Каждому противостоянию соответствует отдельный лист; список игр находится в `Games`, журнал действий — в `Events`. Ячейка `A2` игрового листа содержит состояние игры — не редактируйте её вручную.
