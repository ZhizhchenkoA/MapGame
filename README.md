# Созвездия — игра на графе

Статический сайт для GitHub Pages с картой из [svg-dashboard](https://github.com/iuriigrishin/svg-dashboard) (корневой `index.html` исходного репозитория). Карта содержит 43 области. Соседство получено из SVG-контуров с допуском 1,8 единицы; перед официальной игрой жюри стоит проверить спорные соприкосновения по углам в `site/graph.json`.

## Публикация на GitHub Pages

1. Загрузите эту папку в GitHub-репозиторий.
2. В Settings → Pages выберите GitHub Actions. Workflow `.github/workflows/pages.yml` публикует папку `site`.
3. Откройте опубликованный адрес. До подключения таблицы сайт показывает карту в демонстрационном режиме.

## Google Таблица

1. Создайте Google Таблицу и откройте Extensions → Apps Script.
2. Скопируйте `site/apps-script/Code.gs` в редактор. В Project Settings → Script properties добавьте `JURY_PIN` с длинным случайным значением.
3. Запустите `setup()` вручную и разрешите доступ к таблице. Будут созданы листы `State`, `Events`, `Scores`.
4. Deploy → New deployment → Web app: Execute as **Me**, Who has access: **Anyone**. Скопируйте адрес `/exec`.
5. В опубликованном сайте нажмите «Настройки», вставьте адрес и PIN. URL хранится локально в браузере, PIN — только в памяти вкладки. Участникам откройте сайт без PIN; вводить его должно только жюри.

Лист `Scores` содержит очки за территории, штрафы и итоги; `Events` — журнал действий. `State` — машинное состояние. **Не редактируйте `State` и `Scores` вручную**: счёт пересчитывается скриптом. Для новой игры повторно запустите `setup()` (это удалит журнал предыдущей игры, поэтому сначала сохраните копию таблицы).

Жюри принимает ответы вне сайта и отмечает «Верно»/«Неверно» на карте. Оно может взять карточку, выдать подсказку и сбросить карточку. Перед выдачей подсказки жюри самостоятельно оценивает, не слишком ли она прямая. Все изменения проходят через `LockService`, поэтому первое подтверждённое верное решение закрепляет территорию. Браузер обновляет данные каждые 5 секунд.

Сайт статический; URL Apps Script публичен, поэтому доступ на запись защищён PIN. Для публичного турнира задайте сильный PIN, сообщайте его только жюри и ограничьте круг судей. Запись идёт через `no-cors` POST: браузер не может прочитать ответ операции, поэтому результат проверяется очередным обновлением карты и по листу `Events`.

## Правила, реализованные в скрипте

- Стартовые карточки №3 и №19; 3 попытки на старт, 2 на остальные.
- Взять можно не более 3 карточек, только смежные с захваченными территориями. Команда сама выбирает карточку после освобождения места.
- Сброс и исчерпание попыток запрещают повторную выдачу той же команде. Территория блокируется только после отказа **обеих** команд; до этого она доступна противнику.
- Захват снимает карточку у соперника. Стоимость: №1–27 — 5, №28–42 — 8, №43 — 12. Подсказка после первой ошибки: −2.
- Максимум 90 минут. Досрочное завершение — когда у обеих команд нет карточек и доступных новых территорий.

В исходном тексте правил есть противоречие: сброшенная задача доступна противнику, а территория становится серой после исчерпания возможностей обеих команд. Реализация трактует серый цвет как **двустороннюю блокировку**.
